# ELTIGRETV

Datos publicos de la app ELTIGRETV (Android TV) de ELTIGRELABS.

- `catalog.json`: catalogo de la seccion Cine y Series. Todo el contenido
  viene de archive.org y es dominio publico o licencia abierta, verificado
  titulo por titulo (archivo directo comprobado). La app lee este archivo
  desde la URL raw de este repo, con cache local y respaldo embebido.
- `playlist.m3u`: lista de canales de TV en vivo de la app (fuentes
  publicas verificadas: manifiesto, segmento y codecs comprobados).

Uso personal. Los canales y peliculas pertenecen a sus respectivos
titulares; aqui solo se enlazan fuentes publicas.
